## Folder structure

```
index.html          The album web page (served by GitHub Pages)
photos/day-1|2/     Web-sized photos (max 2048 px) shown in the viewer
thumbs/day-1|2/     Small previews used in the grid
originals/day-1|2/  Full-resolution photos for download
originals/videos/   Original video files
videos/             Browser-friendly MP4 videos and poster images
album.json          List of every photo and video with its size and capture time
```

## Downloading

- **One photo:** open it in the album and click **Download original**.
- **Everything:** on this repository page click **Code → Download ZIP**.
